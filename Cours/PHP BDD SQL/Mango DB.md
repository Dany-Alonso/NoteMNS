# MangoDB ?

MangoDB est du NoSQL (Not Only SQL) orienté documents*. Les données sont généralement stocké en JSON ou en BSON. L'ensemble des documents forme des collections, l'avantage de ce système est :
- Sa flexibilité car son schéma de BDD n'est pas fixe
- Haute performance
- Scalabilité horizontale
